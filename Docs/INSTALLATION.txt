KICKFORGE v0.8 – Installation (Windows, FL Studio)
==================================================

1) Den Ordner "Kickforge.vst3" kopieren nach:

     C:\Program Files\Common Files\VST3\

   Windows fragt nach Admin-Bestätigung – einfach bestätigen.
   (Eine ältere Kickforge-Version dort vorher ersetzen.)

2) FL Studio öffnen:
     Options  >  Manage plugins  >  "Find installed plugins"

   Kickforge erscheint danach bei den Instrumenten (Generators).

3) Kickforge.exe ist die Standalone-Version: startet ohne DAW.
   Audio-Ausgang oben links unter "Options" einstellen,
   dann mit dem KICK-Button oder per MIDI-Keyboard spielen.

Sample-Bibliothek (neu in v0.8)
------------------------------
- Beim ersten Start sucht Kickforge in Downloads, Dokumenten, Desktop, Musik und
  Splice nach "Kick Builder"- und "Kick Vault"-Ordnern (z. B. Teknovault).
  Das dauert einen Moment. Oben in der LIBRARY-Leiste steht danach, wie viele
  Samples und Kits gefunden wurden.
- Andere Ordner: BIBLIOTHEK ▾ → "Ordner hinzufügen…".
- KIT ◀ ▶ lädt ein komplettes Kit (Click + Punch + Rumble + Top).
- ZUFALL würfelt eine neue Kombination, KEY LOCK stimmt sie auf KEY.
- In jeder Schicht: ◀ ▶ blättern, auf den Namen klicken = Liste, RND = Zufall.
  Regler: GAIN, PITCH, DRIVE, OFFSET (Einsatz früher/später), DECAY.
- SYNTH/SAMPLE schaltet eine Schicht zwischen Synthese und Sample um.
  ON schaltet die Schicht stumm.

Bedienung
---------
- Presets: Pfeile oder Liste oben (Industrial = 150 BPM, Harsh = 160 BPM).
  Mit HOST SYNC passt sich die Länge automatisch an das FL-Tempo an.
- KEY = Grundton der Kick. KEY TRACK an: die gespielte Note bestimmt den Ton.
- Eigenes Sample in eine Schicht: WAV auf CLICK / PUNCH / RUMBLE / GRIT ziehen
  (oder LOAD). SAMPLE-Schalter = Sample statt Synthese, X = entfernen.
- VARIATION ändert das Rauschen → gleiche Einstellung, neue Textur.
- Doppelklick auf einen Knob = Standardwert.
- Werte lassen sich tippen: "2.5k", "120ms", "1.2s".
- EXPORT WAV schreibt die aktuelle Kick als 24-Bit-WAV.
- SAVE speichert ein eigenes Preset (inkl. Sample-Pfaden).
